--------------------------------------------------------------------------------
Every single API response follows this unified format:

Success Response (HTTP 200/201):
{
  "success": true,
  "message": "Human readable summary message",
  "messages": [],
  "data": { ... }
}

Error Response (HTTP 400/401/404/500):
{
  "success": false,
  "message": "Human readable error summary",
  "messages": ["Validation error detail 1", "Validation error detail 2"],
  "statusCode": 400
}

3. AUTHENTICATION & LOGIN FLOW
--------------------------------------------------------------------------------
The app uses Phone OTP authentication (JWT Bearer Token).

A. Request OTP (Login / Register):
   Method: POST
   URL:    http://32.195.54.237:3000/auth/login
   Body:
   {
     "phone": "+8801811000001"
   }
   Response:
   Returns `{ success: true, message: "...", data: { sent: true, otp: "123456" } }`
   *DEV NOTE: In development mode, the OTP is ALWAYS 123456.*

B. Verify OTP (Obtain Tokens):
   Method: POST
   URL:    http://32.195.54.237:3000/auth/verify-otp
   Body:
   {
     "phone": "+8801811000001",
     "otp": "123456"
   }
   Response Data:
   {
     "accessToken": "eyJhbGciOi...",
     "refreshToken": "eyJhbGciOi...",
     "user": {
       "id": "uuid-here",
       "phone": "+8801811000001",
       "isProfileComplete": true,
       "nextStep": "MAIN_APP"    // or "PROFILE_SETUP"
     }
   }

C. Authorization Header (for all protected endpoints):
   Authorization: Bearer <accessToken>

D. Refresh Token:
   Method: POST
   URL:    http://32.195.54.237:3000/auth/refresh-token
   Body:
   {
     "refreshToken": "eyJhbGciOi..."
   }

E. Pre-Seeded Test Accounts:
   Phones: +8801811000001 through +8801811000008
   OTP:    123456 (valid for all seeded accounts)

7. MATCHES & CHAT (REST + WEBSOCKETS)
--------------------------------------------------------------------------------
A. List Matches:
   Method: GET
   URL:    http://32.195.54.237:3000/matches

B. 48-Hour Match Expiration Rule:
   Matches expire 48 hours after creation unless a first message is sent!
   Sending a message makes the match permanent.

C. List Conversations:
   Method: GET
   URL:    http://32.195.54.237:3000/chat/conversations

D. Get Message History:
   Method: GET
   URL:    http://32.195.54.237:3000/chat/messages/:conversationId?page=1&limit=30

E. Send Message via REST:
   Method: POST
   URL:    http://32.195.54.237:3000/chat/messages
   Body:
   {
     "conversationId": "uuid",
     "content": "Hello there!",
     "type": "TEXT" // TEXT | IMAGE | LOCATION
   }

F. Real-Time Chat (Socket.IO):
   Client Library: socket_io_client (Flutter)
   Connection URL: http://32.195.54.237:3000
   Connection Options:
   {
     "transports": ["websocket"],
     "query": { "token": "YOUR_JWT_ACCESS_TOKEN" }
   }

   Socket Events:
   - Emit 'join_room':        { "conversationId": "uuid" }
   - Emit 'send_message':     { "conversationId": "uuid", "content": "Hi", "type": "TEXT" }
   - Listen 'receive_message': Receives incoming message payload
   - Emit 'typing':           { "conversationId": "uuid", "isTyping": true }
   - Listen 'user_typing':     Receives typing status of partner
   - Listen 'user_status':     Receives online/offline updates ({ "userId": "uuid", "online": true })
